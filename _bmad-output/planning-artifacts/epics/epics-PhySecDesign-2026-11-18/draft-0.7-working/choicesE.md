CE-03 | 6.3a | reading | A source asset ID identifies a device only when unique in the file and in the project | Unique in the project only | FR-58 says "reliably unique" without defining it.
CE-04 | 6.3a | reading | A row with no identifier matches the device an earlier import created from an identical row, by a stored fingerprint of its mapped values; otherwise it is New | Send every row without an identifier to Needs review on re-import | FR-58 forbids extra devices on re-import and forbids identity by name alone.
CE-05 | 6.3a | reading | Group-level select only for New and Unchanged rows without errors | Group select for Changed rows too | The UX specification limits group select to "straightforward rows".
CE-06 | 6.4 | value | Field list filters named "Awaiting placement" and "Not site-confirmed" | "Unplaced" and "Unverified" | The PRD addendum asks for filtering by verification state and gives no labels.
CE-07 | 6.5 | reading | Bulk cleanup is recorded in the project's change log, open to project members | Record it in the administrator's activity log as well | FR-59 asks for "an activity record"; FR-71's log is administrator-only and separate from project history.
CE-08 | 6.5 | reading | Only the person who ran a cleanup can undo it, in the same session | Any Editor can undo it later | FR-59 applies the own-session undo of FR-21 and FR-55.
CE-09 | 6.5 | reading | A revision restore returns drafts removed by a cleanup but not import-created records | A restore returns neither | FR-22 returns deleted drafts; imported records are existing equipment, which a restore never changes.
CE-10 | 6.6a | reading | Service or reconfigure work is recorded with the scope's Installed mark; lifecycle and location do not change | A separate "Service done" mark | The state model keeps one work-recorded fact per device per scope for every Work now action.
CE-11 | 6.6a | reading | Reversing Installed on a device that was already existing clears the scope's mark, keeps it Existing, and returns a relocated device to its earlier location | No reversal on such devices; a field change is recorded instead | FR-55 says reversal to Proposed does not apply to existing equipment but gives no way to undo a mistaken mark on it.
CE-12 | 6.7 | reading | Preselected category: Add new, Relocate, Service or reconfigure, Replace and Remove give Work now; None and Retain give Reference only | None and Retain give Inspect or test only | FR-45 says "preselect planned changes" and the state model forbids Work now for None and Retain.
CE-13 | 6.7 | reading | Core checks are required by default for Work now devices only; Inspect or test only gets the checks an Editor selects; Reference only gets none | Core checks also required by default for Inspect or test only | FR-45 says selected inspections "can have checks" and reference equipment is not recommissioned.
CE-14 | 6.7 | value | A planned removal not yet recorded is listed as "Removal not recorded" | "Not removed" | The state model completes a Remove by the recorded removal; no source gives the row's wording.
CE-15 | 6.7 | reading | A reason is asked only when a change moves an item out of Work now | A reason for every category change | FR-45 asks for a reason "for meaningful changes" without defining them.
CE-16 | 6.8a | value | A refused save onto a removed device is labelled "not saved: device removed" | "not saved: device archived" | Follows the wording pattern of the other refused-save labels.
CE-17 | 6.8b | reading | Cable ends flagged Needs connection review count in the project list's attention count | Shown only inside the project | The state model lists Needs connection review among the attention indicators.
CE-18 | 6.9a | reading | A restored device returns as Existing with condition Unknown | Keep the condition it had when removed | The state model says restoration does not verify the installation.
CE-19 | 6.9a | reading | A restored device's checks are flagged Retest required | Flag them Needs review | FR-36 says old tests are not evidence of the restored installation, and FR-28 lists return to service as a retest cause.
CE-20 | 6.9a | decide | A label or asset ID now used by another active device must be decided before the restore is confirmed | Allow the duplicate and flag both devices | No source covers a clash on restore.
CE-21 | 6.9a | reading | Restoring a device is refused while no scope is active | Allow it and record it with no scope | Restoration is a recorded site fact like removal, and with no active scope only issues, warranties and service visits can be recorded.
CE-23 | 6.10 | reading | A revision of an earlier scope cannot be designated the new scope's current issued design | Allow it with a warning | FR-61 designates a revision "for the active work scope".
CE-24 | 6.11 | reading | Archiving is refused while an inventory import or a package generation is running | Let the job finish in an archived project | An archived project cannot be edited (FR-37), and a running job would still be writing to it.
CE-25 | 6.11 | value | A refused save into an archived project is labelled "not saved: project archived" and is not retried | Retry after un-archiving | Follows the wording and behaviour of the other refused-save labels.
CE-26 | 6.11 | decide | While a project is archived, every reviewer link, including one to a closeout record, opens read-only and accepts no comment or decision | Keep accepting decisions on fixed records, such as final acceptance of a closeout | FR-37 pauses editing; no source says whether a review decision counts as editing.
CE-27 | 6.12a | reading | End date is the start date plus the term, and In warranty includes the end date | In warranty ends the day before the end date | FR-65 says the end date is calculated; the UX example reads "runs to 12 Nov 2027".

CE-30 | 6.12a | value | Warranty term in whole months, minimum 1 | Days, or months and years | FR-65's example is a 12-month warranty.
CE-31 | 6.12b | reading | A visit time cannot be earlier than the reported time, and neither can be in the future | Accept any times | FR-65 visits record what happened; scheduling is outside the proof of concept.
CE-32 | 6.12b | reading | With no scope active, an existing visit can be corrected but a new one needs Start service visit | Record new visits with no scope | FR-65 routes a visit with no active scope through Start service visit.
