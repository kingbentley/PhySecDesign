# Reference context

Research date: **2026-11-16** (America/Chicago).

This is a brief review of the original product references for the guided Site Studio PRD. The descriptions below summarize capabilities presented by the products' official sites. They are reference context, **not implemented Site Studio scope, accepted requirements, or vendor recommendations**.

| Reference | Relevant planning capabilities presented by the official source | Authoritative sources |
| --- | --- | --- |
| CCTV Design Tool | A browser workflow for placing cameras on floor plans or satellite maps, adjusting field of view and mounting parameters, and displaying coverage zones and pixel density. It also describes cable routing, equipment lists, and PDF proposals. | [CCTV Design Tool product overview](https://www.cctvdesigntool.com/) |
| SiteOwl | Design tools include drag-and-drop placement, reusable device templates, visibility of existing equipment, and generated bills of materials. Its planning tools consolidate installed inventory across locations and use equipment age and warranty information when planning replacements or upgrades. | [SiteOwl design](https://getsiteowl.com/product-design/), [SiteOwl planning](https://getsiteowl.com/product-planning/) |
| JVSG | Its IP Video System Design Tool combines imported plans and 3D models with camera placement, lens and pixel-density calculations, coverage visualization, cable-path measurements, bandwidth and storage estimates, and design exports. | [JVSG IP Video System Design Tool overview](https://www.jvsg.com/) |
| IPVM Camera Calculator | The public guest interface exposes a map-based project canvas, camera and device tools, floor-plan import, a camera-model catalog, and export controls for presentation, document, spreadsheet, archive, and snapshot formats. These controls were observed; generated outputs and calculation accuracy were not tested. | [IPVM Calculator: Security Camera Design Tool](https://calculator.ipvm.com/) |

## Evidence boundaries

- This review used official product pages only. It does not independently validate marketing claims, numerical accuracy, feature availability by subscription, or suitability for a particular installation.
- IPVM was inspected through its public browser guest interface because the static web reader returned only a JavaScript-required page. No account access or user project files were needed.
- No additional PSP reference documents were supplied for this PRD. This research did not review a complete PSP reference collection or establish standards or compliance conclusions.
- Any capability considered for Site Studio still needs an explicit product decision and a defined acceptance boundary in the PRD.
