# Equipment and cabling reference for OQ-7

Research date: **2026-11-17** (America/Chicago). Narrow official-source grounding for a POC scope recommendation. The recommendations below are product-design inferences, not accepted PRD requirements, implemented features, a technical standard, or installation instructions.

## Recommended POC boundary

1. **Small, editable generic catalog.** Start with equipment families needed by the workflow: cameras; readers, contacts, locks, REX devices and controllers; switches and supporting network/power equipment. Store label, type, location, optional manufacturer/model, notes and relevant planning values. Allow reusable templates and custom entries; an exhaustive manufacturer catalog is unnecessary for this scope.
2. **Doors and gates as assemblies of referenced items.** Give each opening an identity and location, then associate its selected components and controller. Support side/direction labels where useful. Keep these associations separate from actual cable connections. Components remain individual inventory/cost items; an opening or template should not silently count them again. Component presence and quantities stay editable; copying a template does not validate the design.
3. **Manual switch-port schedule.** Capture switch capacity and planned port assignments, with connected device, port label/type and an explicit uplink or reserved designation. Show assigned/available counts and obvious duplicate or over-capacity assignments. Treat unknown capacity as unknown. Capacities come from the selected equipment or user entry, not a universal switch/controller limit. This is planning data, not discovery or configuration of live hardware.
4. **Transparent cable estimate.** For each physical run, keep endpoints, cable type and a routed plan polyline. Calculate the calibrated horizontal route, then add separately entered vertical/riser/drop length and optional extra allowance. Display the breakdown and total; preserve any manual override and its explanation. If plan scale is unknown, report an incomplete estimate rather than a precise total. Avoid adding the same vertical run twice. The manual vertical-length method is a POC simplification; the cited source establishes that height matters, not this exact calculation rule.

These checks support coherent planning records. They do not establish wiring compatibility, PoE adequacy, permitted cable distance, egress/gate safety, controller capacity for all products, or regulatory compliance. Detailed electrical calculations, automatic 3D routing, credential administration and live access-control operations require separate scope decisions.
